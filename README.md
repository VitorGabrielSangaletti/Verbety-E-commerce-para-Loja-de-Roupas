Verbety – Sistema de Vendas para Loja de Roupas

Projeto de TCC (Trabalho de Conclusão de Curso) desenvolvido para a Verbety, uma loja de roupas, com o objetivo de criar uma plataforma completa de vendas online.

O site funciona como um e-commerce completo, com catálogos, home, carrinho, tela de checkout etc. Também conta com uma área de admin onde o dono pode adicionar, remover e fazer o controle geral dos produtos

Funcionalidades

Cadastro e login de usuários com autenticação segura (Spring Security)
Catálogo de produtos com busca e filtro por categoria
Carrinho de compras
Processo de checkout e finalização de pedidos
Área administrativa para gerenciamento de produtos, categorias e clientes

Tecnologias utilizadas

Backend: Java, Spring Boot, Spring Data JPA, Spring Security
Banco de Dados: MySQL
Frontend: HTML, CSS, JavaScrpit

Status 

Em produção
